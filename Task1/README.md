Компоненты системы:
CDN уровень:

    Cloudflare + российские CDN-провайдеры
    
    Кеширование статики в 10+ точках присутствия
    
    Обеспечивает время отклика <100 мс для любого региона

GSLB (Global Server Load Balancer):

    Маршрутизация трафика по принципу:
    
    GeoDNS - по местоположению пользователя
    
    Latency-based - к ближайшему доступному дата-центру
    
    Weighted - балансировка нагрузки между дата-центрами
    
    Health Checks каждые 30 секунд

Региональные кластеры:

    3+ зоны доступности (Москва, СПб, Екатеринбург)
    
    В каждом:
    
    Kubernetes кластер (автомасштабирование 2-10 нод)
    
    PostgreSQL шард (Citus) + синхронная реплика
    
    Redis для кеширования
    
    Мониторинг (Prometheus + Grafana)

База данных:

    Шардирование по регионам (Citus)
    
    Синхронная репликация между зонами (RPO <15 мин)
    
    WAL-архивирование в S3 (бэкапы каждые 5 мин)
    
    Автоматический фейловер через Patroni
    
Резервные копии:
    
    Ежедневные снапшоты в S3
    
    Хранение: 30 дней
    
    Кросрегиональное реплицирование
